# Input_Catcher_3000 — Research mode & OBS setup

Research mode is optional. If you just want a key/mouse overlay for
streaming, you don't need any of this — leave the Research mode box
unticked and start the overlay as usual.

Research mode is for people who record gameplay and want a precise
record of what they pressed and when: a log file with millisecond
timestamps, an on-screen clock, and a marker key. If you also connect
it to OBS, every marker is stamped with OBS's own recording time, so
the log lines up with the video exactly.

## What you need

- Windows 10 or 11
- OBS Studio 28 or newer (the WebSocket server is built in from 28 on;
  older versions need the separate obs-websocket plugin)
- Input_Catcher_3000 v1.1 or newer

## Part 1 — Turn on OBS's WebSocket server

This is a one-time setup on your own computer. The password here is
yours, generated by your OBS; nobody else's password is involved.

1. Open OBS.
2. In the top menu, click **Tools** → **WebSocket Server Settings**.
3. Tick **Enable WebSocket server**.
4. Leave **Server Port** at **4455** unless something else on your PC
   already uses it.
5. Under Authentication, either:
   - leave **Enable Authentication** ticked and click
     **Show Connect Info** to see your password, or
   - untick it if you'd rather not use a password (only your own PC can
     reach this server, so either is fine for home use).
6. Click **OK**.

If Windows Firewall pops up asking whether to allow OBS on your network,
you can click **Cancel**. Input_Catcher_3000 talks to OBS on the same
computer only, and that works with or without the firewall rule.

## Part 2 — Connect Input_Catcher_3000

1. Launch **Input_Catcher_3000.exe**. The settings window opens.
2. Under **Research mode**, tick **Enable**.
3. Tick **OBS sync**.
4. Enter the port (4455) and the password from step 5 above. Leave the
   password blank if you turned authentication off.
5. Click **Test OBS**. You should see something like
   `OK: OBS 32.2.2, websocket 5.7.4, recording=no`.
6. Click **Start Overlay**.

Your settings, including the password, are saved to
`input_catcher_3000_config.json` next to the exe and never leave your
computer.

## Part 3 — Using it

- **F8** drops a numbered marker. Press it at the start of each thing
  you want to measure. You'll see `MARK 1`, `MARK 2`… in the overlay,
  and each one is written to the log with OBS's current recording time.
- **F9** starts or stops OBS recording without touching OBS.
- The clock at the top of the overlay (`00:12.345`) shows seconds since
  the overlay started. If you're not using OBS sync, this clock is how
  you line the log up with the video: read it off any frame.
- Both keys can be changed in the settings window.

Log files are written to a `research_logs` folder next to the exe, one
per session, named by date and time. They're plain text (one JSON
object per line) — see `RESEARCH_MODE.md` for every field and how to
align them with your footage.

## Troubleshooting

**Test OBS says "Failed: No connection could be made…"**
OBS isn't running, or the WebSocket server isn't enabled, or the port
doesn't match. Re-check Part 1.

**Test OBS says "OBS rejected the connection (wrong password?)"**
The password doesn't match. In OBS, Tools → WebSocket Server Settings →
Show Connect Info, and copy it again. Make sure there's no extra space.

**Test OBS says "OBS requires a password"**
Authentication is on in OBS but the password box here is empty.

**Markers work but the log says `"event":"skipped"`**
The overlay couldn't reach OBS at that moment. Markers still record
with the overlay's own clock; only the OBS timecode is missing. It
retries automatically every few seconds.

**I started recording before pressing F9 / I use OBS's own hotkey**
That's fine. Markers stamp whatever OBS is currently recording; F9 is
just a convenience.

**Nothing happens when I press F8**
Check the marker key in settings, and that Research mode is enabled.
Some games grab function keys for themselves; pick a different key if
so.

## Privacy

Research mode logs every key and mouse button you press while it's
running, to a file on your own disk. Nothing is uploaded anywhere.
Don't leave it running while typing passwords, and delete logs you
don't need.
